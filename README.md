---

# 📌 Project Overview

The **Environmental Intelligence & Sustainability Analytics Platform** is an end-to-end Environmental Data Engineering, Machine Learning, Forecasting, and Business Intelligence solution developed as part of the IIT Jodhpur Capstone Project.

The platform integrates climate, air quality, and forest sustainability datasets to generate environmental intelligence, assess sustainability performance, forecast future environmental conditions, and support executive decision-making through interactive Power BI dashboards.

The project demonstrates the complete analytics lifecycle:

**Data Collection → Data Engineering → Data Cleaning → Feature Engineering → Machine Learning → Forecasting → Scenario Analysis → Interactive Power BI Dashboards → Executive Decision Support**

# 🌍 Environmental Intelligence Layer

The platform generates multiple environmental intelligence indicators.

### Climate Score

Measures climate conditions using long-term temperature anomalies.

### Pollution Score

Evaluates pollution severity using AQI and PM2.5 indicators.

### Forest Score

Measures ecosystem sustainability using forest cover.

### Environmental Health Index (EHI)

Overall environmental health indicator based on:

- Forest Score
- Climate Score
- Pollution Score

### Sustainability Score

Represents the overall sustainability performance.

# ▶️ Running the Project

## Clone Repository

```bash
git clone https://github.com/VahidaSS/CapstoneProject.git
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Execute Python Pipeline

```bash
python pipeline.py
python feature_engineering.py
python analysis_forecasting.py
```

## Open Dashboard

Open the Power BI dashboard (`.pbix`) using Microsoft Power BI Desktop.
